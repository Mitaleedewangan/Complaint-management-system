Complaint Management System
Developed a web-based Complaint Management System designed to streamline the process of filing and managing complaints. The application enables users to register, log in, and submit complaints, 
while administrators can efficiently view, accept, or reject complaints. The system provides real-time tracking of complaint status and ensures secure data management.

Key Features:

User Registration & Login: Secure authentication for user access.
Complaint Submission: Users can file complaints with necessary details like category and description.
Admin Dashboard: Administrators can manage complaints, including accepting or rejecting them.
Real-time Status Tracking: Users can track the status of their complaints (pending, accepted, rejected).
Data Management: Secure storage and management of complaints and user data in a MySQL database.
Technologies Used:

Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
